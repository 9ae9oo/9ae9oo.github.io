# 홈페이지 이미지 교체 목록

아래 파일을 이 폴더에 넣은 뒤 `index.html`의 같은 이름 placeholder를 `<img>`로 교체한다.

- `hero-main.webp`: 인박스와 일간 창을 함께 띄운 대표 이미지
- `inbox-brain-dump.webp`: 시간 미정 할 일이 담긴 인박스
- `anchor-time.webp`: 같은 할 일을 오전·오후·저녁에 나눈 화면
- `daily-timetable.webp`: 타임테이블과 앵커가 함께 보이는 일간 화면
- `focus-mode.webp`: 지금 할 일과 타이머가 보이는 포커스 모드
- `workflow.webp`: 작품과 공정 단계 화면
- `tools.webp`: 메모·해빗·시간 도구를 함께 띄운 화면
- `settings.webp`: 테마·백업·작업 시간 설정 화면

PNG 원본은 별도로 보관하고, 홈페이지에는 용량을 줄인 WebP를 사용한다.
