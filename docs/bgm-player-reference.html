A형 최종 정리

조작은 크게,
구조는 단순하게

현재 곡 카드와 재생목록을 한 흐름으로 이어 붙였습니다. 패널을 닫는 동작은 기존 BGM 탭에 맡기고, 패널 안에는 음악을 듣는 데 필요한 정보만 남깁니다.

1
머리 영역 단순화`BGM`과 `재생 중`만 표시합니다. 닫기 버튼은 두지 않습니다.
2
A형 플레이어 유지작은 썸네일, 곡 정보, 진행 막대와 재생 조작을 하나의 카드로 묶습니다.
3
A형 재생목록 유지재생목록 선택 아래에 곡 목록을 항상 표시하고 현재 곡만 강조합니다.
4
모바일 터치 크기 확보주요 조작은 40px 이상, 재생 버튼은 52px, 곡 줄은 48px로 잡았습니다.
`펼치기/접기` 삭제
목록은 이 패널의 핵심이고, BGM 탭으로 패널 전체를 닫을 수 있어 별도의 목록 접기 버튼은 필요하지 않습니다.
