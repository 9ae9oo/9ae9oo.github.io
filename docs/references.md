## 1. TASKET — 핑크 그라데이션 플래너

`refs/tasket-home.png` · `refs/tasket-calendar.png` · `refs/tasket-week.png` · `refs/tasket-diary.png` · `refs/tasket-settings-schedule.png` · `refs/tasket-settings-theme.png` · `refs/tasket-settings-general.png`

**분위기**: 흰 배경 + 상단 핑크 그라데이션 헤더. 아이콘 전용 좌측 레일.

**화면**
- **홈**: 큰 배너 이미지(애니 일러스트) 위에 `September 3 / THURSDAY` 오버레이(우하단). 그 아래 D-day 칩 줄(마감 일정 `D-day` `D-1` …), "오늘의 바스켓"(= 할 일, 체크박스 + "오늘 할 일 추가…"), "컨펌 대기중" 섹션. 우측 레일: 미니 월 캘린더(날짜 밑 색점), 그 날 일정 목록(색 불릿), "다가오는 마감일정"(접힘).
- 상단바: 로고 + 빠른 입력 `생각나는 할 일을 토스! — Space로 언제든 포커스` + 문서 아이콘.
- **캘린더(월)**: 필터 칩(전체/업무/금전/개인 일정, 색점). 월 그리드에 일정 바. 우측: 그 날 일정 + "일정 배치를 기다리는 마감들" + "언젠간 돌아볼 아이디어들".
- **다이어리**: 큰 `3 9월 목요일` + 자유 서술 textarea + "사진 추가". 우측 미니 캘린더 + "Today I…" 체크 프롬프트.
- **설정 → 일정·연동**: "데일리 체크리스트 및 리마인더" — 항목마다 알림시각 칩(`9:00 ×` `12:00 ×` …) + "+ 알림 시간".
- **설정 → 테마**: **앱 컬러**(포인트색 스와치, 커스텀 최대 5개 + 버튼) · **태스크 기본 컬러**(색 미지정 태스크 기본색, 맨 앞 `[테마]` 는 앱 컬러 따라감) · **메인 배너 사진** 토글(끄면 상단 사진 숨김) · **테마 프리셋**(현재 컬러·배경·스티커를 이름 붙여 저장 → 언제든 불러오기, 썸네일 + `적용`).
- **설정 → 일반**: 구글 캘린더 연동(연결됨, 동기화 방향 내보내기/가져오기/양방향, 지금 동기화, 연결 해제, 동기화 초기화) · 수수료 프리셋(플랫폼별 %, 예 크레페 10% → 프로젝트 수입에서 실수령 자동 계산) · 앱 실행(윈도우 시작 시 자동 실행).

**빌릴 점**
- 홈 배너 이미지 위에 **날짜 오버레이** (지금은 이미지가 날짜 아래 별도) → 더 세련됨.
- **테마 프리셋을 "저장/불러오기"** — 지금 우리는 프리셋 5개 고정. 사용자가 현재 상태를 이름 붙여 저장하는 개념 추가 가능.
- **"태스크 기본색 = 테마색 따라감"** 옵션 — 우리 v3 메모 해시태그 색이 이미 이 방향.
- 수수료 프리셋 → 정산 페이지에 이미 유사 개념 있음(재확인).
- 좌측 레일 아이콘 세트 참고(홈/캘린더/폴더/전구/책/슬라이더).

## 2. SCHEDULE-MANAGER — 고양이 패턴 대시보드

`refs/sm-dashboard.png` · `refs/sm-week-timetable.png` · `refs/sm-settings.png`

**분위기**: 연분홍 고양이 패턴 배경 위 흰 카드. 둥근 모서리, 말랑한 그림자.

**화면**
- **FOCUS WINDOW**: 주간 스트립(월~일 + 날짜), 각 칸에 일정 칩 + `◀ ▶`.
- 카드 줄: MEMO(잠금 아이콘) · PROGRESS(일/주/월 토글, 0% 링, "오늘 마감"/"3일 내 마감" 카운트) · TO-DO(추가 + 개수) · 타이머(스톱워치/알람/집중/플래그 아이콘, `00:00:00`, START/RESET).
- **CHECKLIST 표**: 월 네비 + 복사 + 검색 + 태그 필터 칩. 열: `NO. / 일정 명 / 작업 / 마감 날짜 / D-DAY / 태그 / 메모 / 진행률 / 상태(CHECK)`.
- **위클리 타임테이블**: `좁게 / 보통 / 넓게` 너비 토글, 주 열 + 시각 행(00:00~), 상단에 종일 일정 바.
- **환경 설정** 모달: 좌측 탭 `색상 설정 / 꾸미기 / 일정 / 시스템 / 데이터`.
  - 일정 탭: "동순위 정렬"(가나다순/생성순) · "태그" 편집(색점 + 이름 + Enter) · **"체크리스트 커스텀"**(회차 열 켜기/끄기, D-DAY 열 켜기/끄기 등 표 컬럼 토글, 기본값 복원).
- 우측 위젯: "반복한 뽀모도로 N회", "완료한 D-DAY 타이머 N회" (통계).

**빌릴 점**
- **표 컬럼 켜기/끄기 커스텀** — 우리 작업 페이지·정산 표에 적용 가능(사용자가 안 쓰는 열 숨김).
- **"좁게/보통/넓게" 밀도 토글** — 이미 캘린더 주간에 유사한 것 있었음. 다른 표에도.
- **정렬 기준 선택**(가나다순/생성순) — 동점 일정·메모 정렬에.
- 뽀모도로/타이머 **누적 통계**("N회 완료") — 동기부여 요소.
- 대시보드 카드 = 위젯 그리드 형태(우리 홈 대시보드와 방향 같음).

## 3. 2ASY-CAL — 모눈종이 / 손그림 다이어리

`refs/2asy-calendar.png` · `refs/2asy-weekly.png` · `refs/2asy-daily.png`

**분위기**: 모눈 배경, 손으로 그린 듯한 둥근 셀, 흑백 위주 + 포인트색 최소.

**화면**
- 탭: `캘린더 / 위클리 / 데일리 / 포커스 / 다이어리`. 좌측: 아바타 + 미니 캘린더 + **떠 있는 메모쪽지**("09-03 06:02 / sdfsdf"). 하단 `+ 노트`, `A- / A+`(글자 크기), `✓`.
- **캘린더**: 손그림 셀 월 그리드. 우측 "DAY RECORDS"(총 N컷, 구분/내용/시간 표) + 하단 "9월 habit 달성률" 막대(약/운동/치카/샤워/독서 %).
- **위클리**: 날짜 네비 + DIARY 열(9.1~9.11 날짜 카드) + LOG 열 + habit 그리드(M~SU 색점) + 월 1~30 미니 히트맵.
- **데일리**: To-Do(날짜 아코디언, 드래그 손잡이) · Time Table(01:00~24:00 라디오) · **WORK NOTE**(날짜/작업/작업량 `N화 M컷`/걸린시간 `시 분`, `00:00`, 시작·종료, `+ 기록 추가`) · **TODAY PLAN**(계산 기준: 스케치, 목표량 10, 진행 점, 배경/스케치/선화/선화수정 개수) · Timestamp(입력 + stamp).

**빌릴 점**
- **WORK NOTE / TODAY PLAN** = 우리 작업 페이지의 "컷 단위 진행"과 겹침. 특히 **"작업 시간 측정(시작/종료) + 컷 기록"** 을 작업 페이지에 붙이면 실제 작업 로그가 됨. `plan-v3` #4 이후 확장 후보.
- **habit 달성률 막대 / 미니 히트맵** — 우리 해빗 그리드에 요약 막대 추가.
- 떠 있는 **퀵 메모 쪽지**(항상 위) — 지금 메모 패널과 별개로, 초경량 1줄 메모.
- 글자 크기 `A- / A+` 전역 토글 — 접근성.

## 4. 나기메모 (nagi-memo) — 트위터식 스티커 메모  ★ 메모 개편의 직접 레퍼런스

`refs/nagi-note.png` · `refs/nagi-list.png` · `refs/nagi-trash.png` · `refs/nagi-settings.png`

**분위기**: 트위터 카드 그대로. 흰 카드 + 연핑크 배경. 프로필(아바타 + @핸들 + 인증마크).

**화면**
- **스티커 노트 창**: 상단 좌 pin/drop/moon/색점, 우 `+` · 문서 · `×`. 프로필 줄(아바타 + `오늘 할 일 @note ✓` + 트위터 새). "더블클릭해서 편집하기". 하단: 날짜 `2026.09.03 06:05` + 이미지/하트/다운로드/자물쇠.
- **서식 팝오버**: `서식 / 0자`. 줄1 `B I U S 🖊(형광펜) </>`. `색 ● ● ● +`. `크기 A- 14 A+`. `글꼴 Aa`. 줄2 정렬(좌/중/우) · 인용(`"`) · 링크. `✕ 서식 지우기` + `?`.
- **트위터 리스트 뷰**: 새 아이콘 · 휴지통(4) · 폴더+ · `+` · `×`. `검색…`. 필터 칩 `전체 27 / 미분류 / ★중요 2 × / 오늘 할 일 0 × / ⌄`. 카드 = **굵은 이름 + @핸들 + 이모지/📌**, 본문 2줄 미리보기, 아래 분류 라벨(`분류 없음` / `테미스` / `★중요`). 일부 📌 고정.
- **휴지통**: "휴지통 · 4개" / 비우기. 삭제일 + 복원↺ + 완전삭제🗑.
- **설정**: 기본 메모지(라이트/다크 + 강조색 스와치) · **아이콘**(메모·목록 심볼 5택 + SVG 업로드) · **기본 프로필**(여러 프로필: `개구 @9aeoo` `중요 메모 @Reminder` `오늘 할 일 @note [기본]` `노트 @Note` `테미스 @TEMIS` `코딩 @coding`, 각 색점 + ×. 메모의 프로필 사진 우클릭 → "현재 프로필 등록하기") · 시작 옵션(자동 실행) · 편집(맞춤법 검사).

**빌릴 점** (우리 `plan-v3` #1 과 대조)
- 우리가 이미 반영: 제목 없음, 검색, 해시태그/분류 칩, 잠금, 서식 바(B/I/U/S/형광펜), contentEditable.
- **아직 참고할 것**:
  - **서식 팝오버를 별도 플로팅**으로 (카드에 붙이지 않고). "글자 수 카운터", "서식 지우기", 색/크기/글꼴/정렬/인용/링크까지.
  - **프로필 개념** — 메모마다 `이름 @핸들 + 아바타 + 색`. 우리는 해시태그로 갔지만, "프로필 = 저장된 분류 프리셋(이름+색+아이콘)" 으로 절충 가능. 트위터 느낌은 프로필이 만듦.
  - **📌 고정(핀)** — 북마크와 별개로 특정 메모를 리스트 최상단 고정.
  - **휴지통(soft delete) + 복원** — 지금은 즉시 삭제. 실수 방지로 휴지통 도입 가치 큼.
  - 필터 칩에 **개수 표시**(`전체 27`, `★중요 2`).
  - 카드/전체 **이미지 첨부**.

## 5. 그레이스케일 저널 앱 — TODO / JOURNAL / WEEK

`refs/journal-todo.png` · `refs/journal-journal.png`

**분위기**: 완전 무채색, 알약 버튼, 넓은 여백. "print!" 로 인쇄 전제.

**화면**
- 좌측: 아바타 + "사용자님의 공간" + 편집, 연/월, `← Today →`, "Notes", 미니 캘린더. 하단 `🌤 32°`, 시계, `♪ MUSIC`.
- **TODO**: 날짜 큰 제목 + 색점. "오늘의 한마디". 3열 `필연 / 성장 / 자유`(각 textarea) + 아래 같은 이름 섹션. `📅 적용` / `루틴 적용`. timestamp + stamp. 하단 `print! / 루틴 / 편집`.
- **JOURNAL**: `MORNING / GRATITUDE(감사한 점 1·2·3) / DIARY / MOOD(♡행복 ○보통 …슬픔 !화남 ✦설렘) / DREAM("나는 이미 ___이다")`. `print!`.

**빌릴 점**
- **구조화된 저널 템플릿**(아침/감사/일기/기분/꿈) — 우리 다이어리(있다면)나 홈에 "오늘의 한마디" + 기분 선택.
- **루틴 적용** — 어제 항목을 오늘로 복제하는 버튼.
- **print!** — 하루/한 주를 인쇄용으로 내보내기.
- **MOOD 태그** — 기분 기록(캘린더 날짜에 기분 색).
- 무채색 + 알약 = "미니멀" 프리셋 후보(테마 시스템에).

## 종합 — 우선 반영 후보

1. **메모: 서식 팝오버 분리 + 프로필/핀 + 휴지통** (나기메모) → `plan-v3` #1 후속.
2. **표 컬럼 커스텀 + 정렬 기준** (SCHEDULE-MANAGER) → 작업/정산 표.
3. **작업 시간 측정 + 컷 로그** (2ASY WORK NOTE) → 작업 페이지 확장.
4. **테마 프리셋 저장/불러오기, 홈 배너 날짜 오버레이** (TASKET) → 테마 시스템.
5. **구조화 저널 + 기분 + print** (그레이스케일) → 새 다이어리 화면.
