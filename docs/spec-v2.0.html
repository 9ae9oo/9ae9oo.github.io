Mini Workspace

웹툰 작가를 위한 통합 브라우저 작업 도구 — 기획서 v2.0
작성일 2026.09.01 HTML / CSS / JavaScript 반응형 (PC + 모바일)
01 — Overview

프로젝트 개요

Mini Workspace는 웹툰 작가의 일상 업무에 필요한 도구들을 하나의 브라우저 탭 안에 통합한 웹 앱입니다. 별도 설치 없이 브라우저만 있으면 PC와 모바일 모두에서 동작하며, 모든 데이터는 브라우저 내장 저장소(LocalStorage)에 보관되어 새로고침 후에도 유지됩니다.

원래 Python(PyQt6) 데스크톱 앱으로 구상되었으나, 빠른 개발과 모바일 대응을 위해 웹 기술(HTML/CSS/JS)로 전환되었습니다. 이전에 제미나이로 만들었던 "WorkSpace Pro" 프로토타입에서 정산 장부와 음악 플레이어 요소를 흡수 통합했습니다.

별개 프로젝트 주의: 초기 대화에서 논의된 "독립형 YouTube/SoundCloud 음악 플레이어"는 이 Mini Workspace와 별개의 프로젝트입니다. 여기서의 음악 플레이어는 워크스페이스 상단 바에 내장된 위젯입니다.
02 — Architecture

위젯 아키텍처 (3단계)

모든 위젯은 사용 빈도와 정보량에 따라 3가지 레벨로 나뉩니다. PC에서는 여러 위젯이 동시에 표시되고, 모바일에서는 한 번에 하나씩 전체 화면으로 전환됩니다.

03 — Music Player

음악 플레이어 상단 고정바

화면 최상단에 항상 고정되어, 사이드바 토글이나 페이지 전환과 무관하게 언제든 음악 조작이 가능합니다.

항목명세

04 — Calendar

캘린더 전용 페이지

월간/주간/일간 3종 뷰를 전환하며, 해빗 트래커가 모든 뷰에 통합 표시됩니다. 투두리스트와 데이터를 공유하고, 브라우저 데스크톱 알림을 지원합니다.

기본 뷰: 월간

항목명세
기본 화면월간 그리드 + 옆/상/하단에 그 달 상세 요약 패널
날짜 미리보기각 칸에 일정 요약(점 또는 짧은 텍스트) 표시
상세 보기미리보기 클릭 → 상세 패널 열림 (시간, 제목, 색상)
해빗 표시각 날짜 칸에 ●●○ 형태로 완료 여부 점 표시

주간 뷰

요일별 컬럼 레이아웃. 각 요일 안에 일정 블록 + 해빗 체크 줄이 함께 표시됩니다.

일간 뷰 (데일리 플래너)

항목명세
상단 영역종일 일정 + 시간 없는 해빗/투두
타임라인세로 스크롤, 사용자가 설정한 기상시간부터 24시간
일정 추가타임라인 위에서 드래그로 시간대 직접 선택 (구글 캘린더 방식)
메모새 기능 없이 기존 메모장 위젯을 플로팅으로 옆에 배치해서 사용

일정 기능

항목명세
반복 일정일/주/월 단위 반복 지원 (시간 단위 불필요)
반복 수정전체 일괄 수정/삭제만 (특정 회차 예외처리 없음)
색상 태그일정마다 색을 직접 지정 가능 (투두는 그룹색 기본값에서 상속)
알림브라우저 데스크톱 알림 (Notification API). 탭이 열려 있을 때만 작동 — 수용됨

외부 캘린더 연동

해빗 트래커 캘린더 내장

독립 위젯이 아니라 캘린더의 월간/주간/일간 모든 뷰에 통합 표시됩니다.

항목명세
체크 방식단순 체크 (했다/안했다만, 횟수·양 기록 없음)
반복 주기매일 반복만 (요일 지정 불필요)
스트릭연속 달성일(🔥) 일간 뷰에서 표시
월간 표시날짜 칸에 ●○ 점으로 완료 여부
주간 표시요일 컬럼에 체크박스 줄

06 — Todo List

투두리스트 플로팅

예정된 일정 관리가 아닌, 생각날 때마다 던져두는 "인박스" 개념의 할 일 목록입니다. 캘린더와 데이터를 공유합니다.

항목명세
개념인박스형 — 날짜 없이도 추가 가능, 떠오르는 것을 바로 기록
기본 정보제목 + 완료 여부
그룹(폴더)카테고리별 분류 (예: 전체/업무메모/개인일정/기타). 탭 전환으로 해당 그룹만 보기
정렬그룹 내 드래그로 직접 순서 변경. 완료 항목은 자동으로 흐려지고 하단으로
날짜 연동날짜를 붙인 투두는 캘린더 해당 날짜에도 표시됨

캘린더 색상 연동

그룹마다 기본 색을 지정합니다 (예: 업무메모=파랑, 개인일정=녹색). 그 그룹의 투두는 캘린더에서 자동으로 해당 색으로 표시됩니다. 특정 항목만 원하면 개별적으로 색을 덮어쓸 수 있습니다.

데이터 공유 구조

투두 데이터는 단일 저장소 하나에 관리됩니다. 캘린더 페이지에서는 날짜가 있는 투두만 필터링해서 보여주고, 플로팅 투두창에서는 전체 목록을 보여줍니다. 어디서 체크하든 같은 데이터가 동시에 갱신됩니다.

07 — Memo

메모장 플로팅

포스트잇처럼 여러 개를 추가/삭제할 수 있는 플로팅 메모 위젯입니다.

항목명세
서식 지원마크다운 문법: 볼드, 이탤릭, 밑줄, 취소선, 체크박스([ ]), 코드블럭, 인용, 링크, 수평선(---)
입력 방식하이브리드 — 기호 직접 타이핑 + 툴바 버튼(B/I/U 등) 클릭 시 기호 자동 삽입. 둘 다 지원
렌더링실시간 미리보기 (입력하면서 바로 서식 변환, 별도 미리보기 모드 없음)
그룹투두와 동일하게 카테고리별 분류 가능
형태여러 개 포스트잇처럼 추가/삭제 가능
08 — Financial Ledger

정산 장부 (가계부) 전용 페이지

카테고리형 개인 수입/지출 장부입니다. 하나의 거래 기록 원본에서 예산 대시보드, 잔액 계산, 부가세 필터 등 모든 파생 뷰가 자동으로 계산됩니다.

세무 안내: 원천세(3.3%) 계산 등은 참고용이며, 실제 세무 신고 전에는 홈택스 또는 세무사를 통한 확인을 권장합니다.

데이터 모델: 거래 기록 (단일 원본)

날짜 date — 거래 발생일
타입 enum — 수입 / 업무 / 지출 / 세금 / 저축 / 상환 (편집·확장 가능, 설정 페이지에서 관리)
대분류 enum — 타입에 종속되는 하위 카테고리 (업무→어시비/소재비/SW/HW, 지출→식비/병원/교통 등)
금액 number — 원 단위
내역 text — 무엇/누구에 대한 거래인지
결제수단 enum — 계좌 / 카드 / 현금 / 기타
메모 text — 자유 메모

타입 → 대분류 계층 구조

대분류는 타입에 종속됩니다. 거래 입력 시 타입을 먼저 선택하면 해당하는 대분류만 드롭다운에 표시됩니다. 다른 타입의 대분류를 자유롭게 섞어 쓸 수 없습니다.

수입

MG/RS, 주식, 예금/기타

업무

어시비, 소재비, 소프트웨어, 하드웨어, 도서/기타

지출 (변동)

식비, 병원, 관리/공과금, 쇼핑/여가, 교통/기타

지출 (고정)

보험, 통신비

세금

소득세, 부가세, 기타

저축 / 상환

사용자 정의 카테고리

파생 뷰 (자동 계산)

(a) 예산 vs 실제 대시보드 타입→대분류로 그룹핑. 예산/실제/차이 표시. 색상: 예산 내 = 파랑, 초과 = 빨강
(b) 결제수단별 분류 현금+계좌이체 합산 → 통장잔액 유추. 통장잔액 − 이번달 카드값 = 쓸 수 있는 돈
(c) 업무지출 자동 필터 타입=업무인 거래만 자동 추출 → 부가가치세 신고용 목록

수입-지출 요약 계산식

수입 − (업무 + 지출 + 세금 + 저축 + 상환) = 순 수입 요약

이월금

매달 직접 수동 입력합니다 (자동 계산 아님). 계좌/현금 잔액과 지난달 카드 청구액을 입력합니다.

대시보드 UI 구성

영역내용
상단 4개 카드수입 / 지출 합계 / 통장 잔액 / 쓸 수 있는 돈
이월금 입력계좌/현금 + 지난달 카드 직접 입력 박스
카테고리 상세전체 카드를 탭 없이 스크롤. 타입별(수입/업무/지출/저축 등) 순서대로 나열
거래 추가대시보드에서는 안 함. 별도 "거래내역" 탭에서만

표시 형태: 2종

원천세 (3.3%) 계산

별도의 독립 도구가 아니라, 가계부에서 "업무 → 어시비" 카테고리를 선택하고 등록된 어시스턴트를 지정했을 때 자동으로 계산됩니다. 사업소득세 3% + 지방세 0.3% = 3.3%.

부가세

부가세 세액은 직접 입력 (별도 계산기 방식). 업무 타입 거래만 자동 필터링해서 모아보는 것으로 신고 준비를 돕습니다.

카테고리 관리

타입과 대분류의 추가/수정/삭제는 별도 설정 페이지에서 관리합니다. 거래 입력 중에는 새 카테고리를 만들 수 없습니다. (음악 플레이어와 동일한 "재생과 편집 분리" 원칙)

핵심 설계 원칙

🔗

단일 원본 (Single Source of Truth)

거래 기록, 투두, 해빗 등 각 위젯의 원본 데이터는 하나만 존재하고, 여러 화면에서 파생되어 표시됩니다.

🔀

재생과 편집 분리

자주 쓰는 기능(재생, 입력)과 가끔 쓰는 기능(설정, 카테고리 관리)을 분리하여 UI를 깔끔하게 유지합니다.

📱

반응형 전환

PC에서는 넓게 펼치고, 모바일에서는 하나씩 전환. CSS 미디어 쿼리로 자동 전환.

🧩

위젯 독립성

각 위젯은 독립적으로 동작하되, 필요한 곳에서만 데이터를 공유합니다 (투두↔캘린더, 공정표 마감일→캘린더).

11 — Roadmap

개발 우선순위 (안)

핵심 인프라(App Shell)를 먼저 만들고, 위젯을 하나씩 채워 넣는 순서입니다.

0단계: App Shell 상단 음악바 영역 + 사이드바(PC)/하단탭(모바일) 구조 + 페이지 전환 라우팅 + 반응형 기반
1단계: 음악 플레이어 YouTube 재생, 재생목록 5개, 순차/셔플, 설정 페이지
2단계: 메모장 + 투두 포스트잇 메모, 마크다운 실시간 렌더링, 인박스형 투두, 그룹 분류
3단계: 캘린더 월/주/일 뷰, 해빗 트래커, 투두 연동, 반복 일정, iCal 읽기
4단계: 정산 장부 거래 입력/수정, 대시보드(4카드+카테고리 스크롤), 전체표/월간요약, 어시스턴트 등록, 부가세 필터
5단계: 연동·확장 Google Calendar API 양방향 동기화 (선택), JSON 백업/복구
